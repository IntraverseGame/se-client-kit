# Changesets

Pending release notes live here. A pull request that changes a published
package or the Wrapper adds one with `pnpm changeset`, naming the packages and
the bump (major for a break, minor for an addition, patch for a fix). The
release procedure is in
[runbook/client-kit-release.md](../runbook/client-kit-release.md#release).
