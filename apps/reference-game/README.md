# `@intraverse/se-client-reference-game`

A minimal sandboxed game, as a sample for game developers and a fixture for the
Wrapper's tests.

**Status:** pre-release: an empty entry. It is an application, not an npm
package, and is never published.

## What it shows

A game that depends on nothing but the type definitions of the controller
protocol `se.controller/1`: it holds no key and no secret, and it only exchanges
state and choices with the Wrapper through that protocol. It will grow into a
complete example when the protocol is defined.

Specified, not implemented yet: the entry is empty today; this describes what
the sample is specified to show.
